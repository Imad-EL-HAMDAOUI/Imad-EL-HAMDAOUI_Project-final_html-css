# Safe Space – Espace Sans Violence

## 1. Présentation
Had projet howa site web smitou Safe Space, l'objectif dyalo howa n3awno nass yel9aw l'aide w l'informations li محتاجين, w nzido n3erfohom b tari9a dyal talab lmosaa3ada.

## 2. Home Page
Hadi hiya saf7a louwla li katban l'utilisateur. Fiha présentation dyal site w navigation bach y9der ymchi l les autres pages.

## 3. Request Help
F had saf7a, l'utilisateur y9der y3mer formulaire bach yطلب l'aide. Kayna 7ta section dyal les urgences, w possibilité dyal partage dyal localisation.

## 4. AI Assistant
Hna kayna interface dyal chat, fin l'utilisateur y9der ykteb message w ytl3 3la informations w conseils. Kayn 7ta tanبيه belli had assistant machi badil 3la les professionnels.

## 5. Éducation des Parents
Hadi saf7a fiha des conseils w ressources l les parents, b7al kifach yfahmo l'agressivité, kifach yt3amlo b calme, w kifach ytb3o l'éducation positive. Kayna 7ta partie 3la consultation d'un spécialiste.

## 6. Technologies utilisées
- HTML
- CSS
- Tailwind CSS
- SVG Icons

## 7. Objectif du projet
L'objectif howa nsaybo site simple w facile à utiliser, li y3awn f sensibilisation contre la violence w yوجه les utilisateurs l les ressources dyal l'aide.
